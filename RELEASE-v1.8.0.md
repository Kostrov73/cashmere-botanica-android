# Cashmere Botanica v1.8.0

**First public-ready project release / Первая подготовленная версия проекта для публикации**

## Highlights / Главное

- **Two care dates:** planned date and actual completion date are stored separately.
  **Две даты ухода:** плановая дата и фактическая дата выполнения хранятся отдельно.
- **Completed initial watering:** adding a plant with a last-watered date creates a completed watering entry in the calendar.
  **Первый выполненный полив:** при добавлении растения с датой последнего полива в календарь добавляется выполненная запись.
- **Automatic care planning:** the next watering or fertilizing event is calculated from the actual completion date.
  **Автоматическое планирование:** следующий полив или подкормка рассчитывается от фактической даты выполнения.
- **Care history and statistics:** completed procedures are reflected using their actual completion dates.
  **История и статистика:** выполненные процедуры учитываются по фактическим датам.
- **Cashmere Botanica branding:** updated app display name.
  **Название Cashmere Botanica:** обновлено отображаемое имя приложения.

## Android compatibility / Совместимость

- Minimum Android version: 8.0 (API 26)
- Target SDK: 35
- App version: 1.8.0 (versionCode 2)
- Application ID remains `com.greenhome.app`.

## Build / Сборка

Open the project root in Android Studio and build the `app` configuration. The repository does not currently include Gradle Wrapper scripts; see the README for details.

Откройте корневую папку проекта в Android Studio и соберите конфигурацию `app`. В репозитории пока нет Gradle Wrapper; подробности — в README.
